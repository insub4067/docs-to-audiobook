# 읽기 모드 자동 목차 설계

## 상태

채택

## 목적

현재 허용하는 DOCX, PDF, TXT, MD, HWP 파일을 오디오북으로 변환했을 때,
읽기 모드에서 문서의 실제 제목으로 이동할 수 있는 목차를 제공한다.

## 현재 상태

읽기 모드에는 목차 버튼과 바텀 시트가 이미 있다. 원본 텍스트의 Markdown
제목(`#`, `##`, `###`)만 인식하므로, MD 이외 파일은 제목이 있어도 목차가
비어 있을 수 있다.

## 결정

서버의 텍스트 추출 단계에서 확실한 제목을 Markdown 제목으로 정규화한다.

- DOCX는 문단의 제목 스타일을 제목으로 보존한다.
- 모든 파일은 독립 행의 Markdown 제목과 명확한 번호 제목(`1. 제목`,
  `제1장 제목` 등)만 제목으로 인식한다.
- 제목으로 확신할 수 없는 일반 문단과 짧은 행은 제목으로 추측하지 않는다.
- 제목을 찾지 못한 문서는 기존처럼 목차 버튼을 표시하지 않는다.

## 데이터 흐름

1. 업로드 파일에서 원문 텍스트를 추출한다.
2. 추출 결과의 확실한 제목을 Markdown 제목 행으로 정규화한다.
3. 기존 제목 추출·문장 연결 로직이 정규화된 제목을 목차 데이터로 만든다.
4. 기존 읽기 모드의 목차 버튼과 시트가 해당 위치로 스크롤하고 재생 위치를 이동한다.

## 범위

- 지원 파일 형식은 기존 DOCX, PDF, TXT, MD, HWP로 한정한다.
- 읽기 모드의 기존 목차 UI와 재생 동기화 동작을 재사용한다.
- 문서 편집기, Markdown 다운로드, 임의 구간 분할은 추가하지 않는다.

## 오류 및 빈 상태

- 제목이 없으면 목차 버튼을 숨긴다.
- 제목 인식 실패가 파일 텍스트 추출이나 오디오북 생성을 실패시키지 않는다.
- 기존 파일 형식·용량·파싱 오류 동작은 변경하지 않는다.

## 검증

- DOCX 제목 스타일과 번호 제목이 Markdown 제목 및 목차 항목으로 이어지는지 테스트한다.
- 일반 문단이 목차 항목으로 오인되지 않는지 테스트한다.
- 기존 Markdown 제목 목차가 계속 동작하는지 전체 테스트로 확인한다.
