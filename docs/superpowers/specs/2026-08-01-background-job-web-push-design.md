# 백그라운드 오디오북 완료 알림 설계

## 목적

관리자 대용량 오디오북 작업은 브라우저와 무관하게 서버에서 끝까지 처리된다.
사용자는 앱을 열어둔 상태, 앱으로 복귀한 상태, 홈 화면 PWA를 닫은 상태 모두에서
완료 사실을 가능한 빨리 알고 완성본을 보관함에서 확인할 수 있어야 한다.

푸시 전달은 운영체제 설정과 네트워크에 따라 실패할 수 있으므로 Web Push를 작업
상태의 근거로 사용하지 않는다. Supabase의 `background_synthesis_jobs`가 최종 상태를
보관하고, 클라이언트 상태 확인이 결과를 복구하며, Web Push는 즉시 알림을 주는 보조
채널로만 사용한다.

## 선택한 접근

다음 세 접근을 비교했다.

1. 클라이언트 폴링만 사용하면 구현은 단순하지만 앱이 닫힌 동안 알릴 수 없다.
2. Web Push만 사용하면 앱 밖 알림은 가능하지만 권한 거부나 전달 실패 시 완료를 놓친다.
3. 상태 확인과 Web Push를 함께 사용하면 구현 범위는 늘지만 전달 실패와 앱 종료를 모두
   견딜 수 있다.

세 번째 하이브리드 방식을 사용한다. 장시간 작업이 핵심인 기능에서 결과를 놓치지 않는
것이 구현량 절약보다 중요하다.

## 사용자 경험

- 로그인 사용자의 프로필 메뉴에 `완료 알림 받기` 버튼을 둔다.
- 브라우저가 Push API를 지원하고 서버에 VAPID 설정이 있을 때만 버튼을 표시한다.
- 사용자가 버튼을 직접 누른 순간에만 알림 권한을 요청한다.
- 구독되면 버튼 문구를 `완료 알림 켜짐`으로 바꾸고 다시 누르면 구독을 해제한다.
- 관리자 대용량 생성이 시작되면 기존 시작 토스트를 유지하고 `job_id`를 기기에 저장한다.
- 앱이 열려 있는 동안 30초마다, 앱이 포그라운드로 돌아올 때 즉시 작업 상태를 확인한다.
- 완료 상태를 확인하면 클라우드 보관함을 동기화하고
  `오디오북 생성이 완료되었습니다.` 토스트를 한 번만 표시한다.
- 홈 화면 PWA가 닫혀 있으면 운영체제 알림을 표시한다. 알림을 누르면 앱을 열고 작업
  상태와 보관함을 다시 확인한다.
- 알림 권한이 없거나 푸시가 실패해도 다음 앱 실행·복귀 시 상태 확인으로 같은 완료
  토스트와 결과를 복구한다.

## 데이터 구조

Supabase에 서버 전용 `push_subscriptions` 테이블을 추가한다.

| 필드 | 용도 |
|---|---|
| `id` | 구독 행 UUID |
| `user_id` | 알림을 받을 사용자 |
| `endpoint` | 브라우저 Push Service 주소, 기기별 고유 값 |
| `p256dh` | payload 암호화 공개키 |
| `auth` | payload 암호화 인증 값 |
| `created_at` | 생성 시각 |
| `updated_at` | 갱신 시각 |

`endpoint`는 유일해야 한다. 한 사용자가 여러 기기를 쓰면 여러 행을 가질 수 있다.
테이블은 RLS를 활성화하고 사용자용 정책은 만들지 않는다. 브라우저는 이 테이블에 직접
접근하지 않고, 인증된 애플리케이션 API가 `service_role`로 자기 사용자의 구독만 저장·삭제한다.

## 서버 API

### 푸시 설정

`GET /api/push/config`

- `enabled`: VAPID 환경변수가 모두 설정됐는지 여부
- `public_key`: 브라우저 구독에 사용하는 공개키. 비밀키는 절대 반환하지 않는다.

### 구독 등록과 해제

`POST /api/push/subscriptions`

- 로그인 필수
- `endpoint`, `keys.p256dh`, `keys.auth`를 검증한다.
- 같은 endpoint는 현재 사용자 소유로 갱신한다.

`DELETE /api/push/subscriptions`

- 로그인 필수
- 요청 본문의 endpoint가 현재 사용자 소유일 때만 삭제한다.

### 백그라운드 작업 상태

`GET /api/background-jobs/{job_id}`

- 로그인 필수
- `user_id`가 현재 사용자와 같은 작업만 반환한다.
- 응답은 `status`, `error`, `audiobook_id`, `completed_at`만 포함한다.
- `source_text`, Push 구독 정보, 다른 사용자 작업은 반환하지 않는다.

## 서버 완료 처리

1. 오디오와 문장 데이터를 Storage에 저장한다.
2. `audiobooks` 행을 생성한다.
3. 작업을 `completed`로 갱신하고 `source_text`를 지운다.
4. 그 이후 해당 사용자의 모든 Push 구독에 일반적인 완료 payload를 보낸다.

payload에는 다음 값만 넣는다.

```json
{
  "type": "audiobook_ready",
  "job_id": "작업 UUID"
}
```

문서 제목·본문·이메일은 잠금 화면에 노출될 수 있으므로 payload와 시스템 알림에 넣지 않는다.
푸시 발송 실패는 이미 완성된 작업을 실패로 되돌리지 않는다. Push Service가 404 또는 410을
반환한 만료 구독은 삭제한다.

## 클라이언트와 서비스워커

- 클라이언트는 `localStorage`에 아직 확인하지 않은 백그라운드 `job_id` 목록만 저장한다.
- 로그인 완료, 앱 초기화, `visibilitychange`로 포그라운드 복귀, 30초 타이머에서 상태를 확인한다.
- 완료를 확인하면 `window.__syncAudiobooksToCloud()`를 기다린 뒤 토스트를 표시하고 목록에서
  job ID를 제거한다. 같은 완료를 반복 표시하지 않는다.
- 서비스워커는 `push` 이벤트에서 항상 눈에 보이는 일반 알림을 표시한다.
- `notificationclick`에서는 이미 열린 앱 창을 우선 포커스하고, 없으면 `/`를 연다.
- 페이지가 열리면 저장된 작업 상태 확인이 실제 완료 여부를 확정한다. Push payload 자체를
  완료의 근거로 삼지 않는다.

## 환경설정

서버에는 다음 비밀값이 필요하다.

- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT` — 운영자 연락처 형식(`mailto:`)

공개키만 `/api/push/config`를 통해 클라이언트에 제공한다. 비밀키는 Fly Secret으로만 저장한다.
설정되지 않은 환경에서는 푸시 기능만 비활성화하고 기존 상태 확인·클라우드 동기화는 유지한다.

## 오류 처리

- 권한이 거부되면 반복해서 권한 창을 띄우지 않고 프로필 메뉴에 `알림 차단됨`을 표시한다.
- 구독 등록 실패는 한국어 토스트로 알리고 기존 생성 흐름을 막지 않는다.
- 작업 조회가 일시적으로 실패하면 job ID를 지우지 않고 다음 주기에 재시도한다.
- 작업이 `error`이면 서버에 기록된 오류를 사용자용 한국어 메시지로 보여주고 job ID를 제거한다.
- 로그에는 endpoint 전체, 암호화 키, 문서 내용, 인증 토큰을 남기지 않는다.

## 테스트 기준

### 서버

- 인증 없이 구독 저장·삭제·작업 조회를 할 수 없다.
- 다른 사용자의 작업 상태와 구독을 조회·삭제할 수 없다.
- 완료 DB 갱신 이후에만 푸시 발송을 시도한다.
- 푸시 실패가 완성된 오디오북과 작업 완료 상태를 되돌리지 않는다.
- 404·410 구독만 정리하고 일시적 발송 실패는 데이터에서 삭제하지 않는다.

### 클라이언트

- 지원하지 않는 브라우저나 서버 미설정 환경에서는 알림 버튼을 숨긴다.
- 권한 요청은 사용자의 버튼 클릭에서만 실행한다.
- 작업 완료 확인 시 클라우드 동기화와 완료 토스트가 한 번만 실행된다.
- 포그라운드 복귀와 타이머가 미확인 작업을 다시 확인한다.
- 서비스워커가 push 알림을 표시하고 알림 클릭 시 앱을 포커스하거나 연다.

### 회귀

- 일반·익명 사용자의 기존 오디오북 생성 흐름은 변하지 않는다.
- Web Push 설정이 없어도 앱 시작, 인증, 생성, PWA 캐시가 정상 동작한다.
- 프런트 변경에 맞춰 `sw.js` 캐시 버전과 선캐시 자산을 갱신한다.

## 비목표

- 진행률을 시스템 알림으로 계속 갱신하는 기능
- 마케팅·공지 푸시
- 문서 제목이나 콘텐츠가 포함된 잠금 화면 알림
- Web Push를 작업 상태 저장소나 보장 전달 큐로 사용하는 기능
