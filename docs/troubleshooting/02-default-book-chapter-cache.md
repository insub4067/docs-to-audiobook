# 기본 제공 오디오북이 챕터 3개만 나옴

## 증상

기본 제공 오디오북("셜록 홈즈의 모험")이 원래 12챕터짜리인데, 재로그인해도 계속
3챕터만 재생됐다.

## 원인

두 가지가 겹쳐 있었다.

1. **직접 원인**: `DEFAULT_BOOK_SOURCE` 상수가 `sherlock-holmes.md`(전체 12챕터)가
   아니라 `sherlock-holmes-sample.md`(3챕터 발췌본)를 가리키고 있었다. TTS 엔진을
   Supertonic에서 edge-tts로 롤백하는 과정에서 성능 문제 때문에 임시로 만들어
   썼던 파일이 원복이 안 된 채 남아 있었다.
2. **잠재 원인(더 심각)**: 소스 파일 경로를 고쳐도 캐시 키(`_default_book_fingerprint`)가
   음성(voice) 이름만 해싱하고 있어서, 파일 내용이 바뀌어도 캐시가 무효화되지
   않았다. 즉 1번을 고쳐도 예전 3챕터짜리 캐시가 계속 서빙될 뻔했다.

## 해결

- `DEFAULT_BOOK_SOURCE`를 전체 파일로 되돌렸다.
- 캐시 키가 `음성 + 파일 내용`을 함께 해싱하도록 `_default_book_fingerprint()`를
  고쳐(`main.py`), 로컬 디스크 경로와 클라우드 Storage 키 양쪽에 반영했다.

`test_fingerprint_changes_with_content_and_voice` 테스트를 추가하고, 내용 해싱
줄을 일부러 지워 테스트가 실제로 실패하는 것을 확인한 뒤 원복해 검증했다.

## 교훈

캐시 무효화 버그는 "지금 당장 보이는 증상"만 고치면 재발한다. 이번 경우 소스
파일 경로만 고쳤어도 챕터 수는 맞아 보였겠지만, 다음에 내용이 바뀌면 똑같은
버그가 또 나왔을 것이다. 캐시 키가 실제로 무엇이 바뀌면 무효화돼야 하는지
(이 경우 "음성"뿐 아니라 "내용")를 항상 다시 점검한다.
